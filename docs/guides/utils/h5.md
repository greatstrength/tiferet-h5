# H5Client

**Module:** `tiferet_h5.utils.h5`  
**Alias:** `tiferet_h5.H5`

## Overview

`H5Client` is the concrete HDF5 infrastructure utility for tiferet-h5.  It extends `tiferet.utils.FileLoader` for path and lifecycle conventions while implementing `H5Service` via the PyTables API.

The underlying file handle is a `tables.File` object stored as `h5client.h5file`.  Unlike `FileLoader`, `H5Client` fully overrides `open_file()` and `close_file()` — PyTables uses `tables.open_file()`, not Python's built-in `open()`.

All error handling follows Tiferet conventions: errors are raised as `TiferetError` via `RaiseError.execute()` — never as raw Python exceptions.

---

## Initialization

```python
H5Client(path, mode='a', **kwargs)
```

| Parameter | Type | Default | Description |
|---|---|---|---|
| `path` | `str \| Path` | required | Path to the HDF5 file. |
| `mode` | `str` | `'a'` | PyTables open mode. See table below. |

### Open Modes

| Mode | Behaviour |
|---|---|
| `'r'` | Read-only. File must exist and have `.h5` / `.hdf5` extension. |
| `'r+'` | Read-write. File must exist and have `.h5` / `.hdf5` extension. |
| `'w'` | Write. Creates or **truncates** the file. Use with caution. |
| `'w-'` | Write-exclusive. Fails if the file already exists. |
| `'a'` | Append / read-write. Creates the file if absent; never truncates. **Repository default.** |

Repositories should default to `'a'` to avoid silent data loss.

---

## Context Manager

`H5Client` implements the context manager protocol.  `__enter__` opens the file and returns `self`; `__exit__` flushes and closes regardless of whether an exception occurred.

```python
with H5Client('data.h5', mode='a') as h5:
    # h5.h5file is open here
    t = h5.get_or_create_table('/items', ItemDescription)
    ...
# file is flushed and closed here
```

`open_file()` and `close_file()` may also be called manually when a context manager is not appropriate, but the context manager form is strongly preferred.

## Validation Methods

### `verify_mode() -> None`

Validates that the configured mode is in `{'r', 'r+', 'w', 'w-', 'a'}`.  Raises `H5_INVALID_MODE` otherwise.

### `verify_file(path, mode) -> None` _(static)_

Validates the file path for the requested mode:

- Read modes (`'r'`, `'r+'`): checks `.h5` / `.hdf5` extension **and** file existence.
- Write / append modes: checks that the **parent directory** exists.

Raises `H5_INVALID_FILE` or `H5_FILE_NOT_FOUND` on failure.

## File-Level Operations

### `flush() -> None`

Flush all pending write buffers to disk without closing the file.  `close_file()` calls this automatically, but call it explicitly after large batch writes when you need durability before closing.

```python
with H5Client('data.h5', mode='a') as h5:
    for item in large_batch:
        item.to_row(table)
    h5.flush()
```

### `node_exists(path: str) -> bool`

Returns `True` if a node exists at the absolute HDF5 path.

```python
if not h5.node_exists('/features/calc'):
    h5.create_group('/features/calc')
```

## Group Operations

### `create_group(path, title='', create_parents=True) -> Any`

Create a group at `path`.  When `create_parents=True` (the default), any missing intermediate groups are created automatically.

```python
h5.create_group('/features/calc', title='Calculator Feature')
```

### `get_group(path) -> Any`

Retrieve the PyTables group object at `path`.  Raises `H5_NODE_NOT_FOUND` if the path does not exist.

---

## Table Operations

### `create_table(path, description, title='', **kwargs) -> Any`

Create a table at `path` using a `tables.IsDescription` subclass.  The parent group is created automatically if absent.

```python
from tiferet_h5 import TableObject
# ...
t = h5.create_table('/features/calc/steps', StepTableObject.get_description(), title='Steps')
```

Raises `H5_TABLE_CREATE_FAILED` on any PyTables error.

### `get_table(path) -> Any`

Retrieve the PyTables table object at `path`.  Raises `H5_NODE_NOT_FOUND` if absent.

### `get_or_create_table(path, description, title='', **kwargs) -> Any`

Return the existing table if the node exists; otherwise create and return a new one.  The recommended pattern for repository `save()` methods.

```python
t = h5.get_or_create_table('/features/calc/steps', StepTableObject.get_description())
obj.to_row(t)
t.flush()
```

### `append_rows(path, rows) -> None`

Append a list of plain Python dicts to the table at `path`.  String values are encoded to bytes automatically.  Flushes after all rows are written.

```python
h5.append_rows('/items', [
    {'name': 'Widget', 'price': 9.99},
    {'name': 'Gadget', 'price': 24.99},
])
```

### `read_rows(path, start=None, stop=None, condition=None) -> List[Dict]`

Read rows from the table at `path`.  All values are returned as Python natives (bytes decoded, NumPy scalars converted).

- Without arguments: reads all rows.
- `start` / `stop`: slice the row range.
- `condition`: apply an in-kernel PyTables condition string.

```python
# All rows
rows = h5.read_rows('/items')

# Sliced
rows = h5.read_rows('/items', start=10, stop=20)

# Filtered
rows = h5.read_rows('/items', condition='price > 10.0')
```

### `query(path, condition, **kwargs) -> List[Dict]`

Convenience wrapper around `read_rows` that applies a condition string.  Equivalent to `read_rows(path, condition=condition)`.

```python
matches = h5.query('/items', 'name == b"Widget"')
```

Note: string comparisons in PyTables condition strings compare against bytes literals (`b"..."`), not Python string literals.

### `remove_rows(path, condition) -> int`

Remove all rows matching `condition` from the table at `path`.  Deletion is performed in reverse index order to preserve stability.  Returns the number of rows removed.

```python
removed = h5.remove_rows('/items', 'name == b"Widget"')
print(f'Removed {removed} rows.')
```

## Array Operations

### `create_array(path, data, title='') -> Any`

Create an array node at `path` from a NumPy array or Python sequence.  The parent group must already exist.

```python
import numpy as np
h5.create_group('/measurements')
h5.create_array('/measurements/temperatures', np.array([22.1, 23.4, 21.9]))
```

### `get_array(path) -> Any`

Retrieve the PyTables array object at `path`.

```python
arr = h5.get_array('/measurements/temperatures')
data = arr.read()  # returns NumPy array
```

---

## Attribute Operations

### `set_node_attr(path, name, value) -> None`

Set a single metadata attribute on the node at `path`.

```python
h5.set_node_attr('/features', 'schema_ver', '1.0')
```

### `get_node_attr(path, name) -> Any`

Retrieve a single attribute value.  Bytes are decoded to `str`; NumPy scalars are converted to Python natives.

```python
ver = h5.get_node_attr('/features', 'schema_ver')
# '1.0'  (plain Python str, not np.str_)
```

### `get_node_attrs(path) -> Dict[str, Any]`

Retrieve **all user-defined attributes** from the node as a plain Python dict.  System attributes managed by PyTables (`CLASS`, `TITLE`, `VERSION`, etc.) are excluded via `_v_attrnamesuser`.  Pass the result directly to `NodeObject.from_attrs()`.

```python
raw = h5.get_node_attrs('/features/calc')
# {'name': 'Calculator', 'desc': 'Arithmetic ops'}

group_obj = FeatureGroupObject.from_attrs(raw)
```

## Error Codes

All errors are raised as `TiferetError` with the following codes defined in `tiferet_h5.assets.constants`:

| Constant | Error code string | Raised when |
|---|---|---|
| `H5_FILE_NOT_FOUND_ID` | `H5_FILE_NOT_FOUND` | File absent (read mode) or parent dir absent (write/append mode). |
| `H5_INVALID_FILE_ID` | `H5_INVALID_FILE` | File does not have `.h5` / `.hdf5` extension in a read mode. |
| `H5_INVALID_MODE_ID` | `H5_INVALID_MODE` | Mode string is not one of the five valid PyTables modes. |
| `H5_FILE_ALREADY_OPEN_ID` | `H5_FILE_ALREADY_OPEN` | `open_file()` called when the handle is already open. |
| `H5_CONN_NOT_INITIALIZED_ID` | `H5_CONN_NOT_INITIALIZED` | Any operation attempted before `open_file()`. |
| `H5_NODE_NOT_FOUND_ID` | `H5_NODE_NOT_FOUND` | Path does not exist in the open file. |
| `H5_TABLE_CREATE_FAILED_ID` | `H5_TABLE_CREATE_FAILED` | `create_table()` raised a PyTables exception. |
| `H5_QUERY_FAILED_ID` | `H5_QUERY_FAILED` | `read_rows()` / `query()` raised a PyTables exception. |
| `H5_WRITE_FAILED_ID` | `H5_WRITE_FAILED` | `append_rows()`, `remove_rows()`, or `create_array()` failed. |
| `H5_SCHEMA_MISMATCH_ID` | `H5_SCHEMA_MISMATCH` | Reserved for `TableObject.verify_schema()` consumers. |
